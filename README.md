# KuraStream - Centro de entretenimiento local offline premium

Centro de entretenimiento offline premium para anime, películas y series.

## Requisitos previos

Para poder ejecutar este proyecto, necesitas tener instalados en tu sistema:
- **Node.js** v22.0.0 o superior (el motor de ejecución de JavaScript).
- **FFmpeg** (requerido para el procesamiento y generación de vistas previas de video).

## Pasos de instalación

Clona o descarga el repositorio y ejecuta el siguiente comando en la raíz del proyecto para instalar las dependencias:

```bash
npm install
```

## Scripts de ejecución

El proyecto incluye los siguientes scripts definidos en `package.json`:

- **Iniciar la aplicación (Producción):**
  ```bash
  npm start
  ```
- **Iniciar en modo desarrollo (con auto-recarga y watch habilitados):**
  ```bash
  npm run dev
  ```
- **Ejecutar las pruebas unitarias:**
  ```bash
  npm test
  ```
- **Ejecutar el linter para revisar la calidad del código:**
  ```bash
  npm run lint
  ```
- **Formatear el código automáticamente:**
  ```bash
  npm run format
  ```
